### Общее описание проекта

Этот проект представляет собой **мощное веб-приложение для просмотра и редактирования сферических панорам (VR-туров)**. По сути, это полнофункциональный редактор, который работает прямо в браузере и позволяет создавать интерактивные 360-градусные виртуальные туры.

Проект состоит из трёх основных частей:
1.  **Плеер (`viewer.html`, `panorama_player.js`)**: Для просмотра уже готовых панорам.
2.  **Редактор (`edit.html`, `panorama_edit.js`)**: Для создания туров, расстановки точек перехода (`hotspots`), настройки направлений камеры и экспорта/импорта данных.
3.  **Превью (`viewer_preview.html`, `pannellum_preview.js`)**: Вспомогательный инструмент для выбора координат при создании точек.

### Основное предназначение

Проект предназначен для решения следующих задач:

1.  **Создание виртуальных туров (визуальное повествование)**: Вы можете взять серию панорамных фотографий и объединить их в единый тур, где пользователь переходит из одной сцены в другую, кликая по специальным точкам.
2.  **Редактирование в реальном времени**: Вместо того чтобы править JSON-файлы вручную, вы можете открыть редактор, кликнуть по панораме, чтобы добавить точку, и сразу же увидеть результат.
3.  **Визуальное программирование (No-Code подход)**: Создание точек перехода (хотспотов) происходит через интуитивно понятный интерфейс (двойной клик для создания, предпросмотр для настройки направления).

### Ключевые функции

**Для плеера:**
- Отображение сферических панорам с полным управлением (вращение, зум).
- Поддержка переходов между сценами (`hotspots`).
- Работа с внешними (по HTTPS) и локальными изображениями.

**Для редактора:**
- **Создание точек перехода (`Hotspots`)**: Двойной клик по панораме.
- **Предпросмотр**: Загрузка целевой панорамы в отдельном окне для точной настройки направления камеры.
- **Редактирование**: Изменение названия, текста и типа существующих точек.
- **Импорт/Экспорт**: Сохранение всех настроек тура в JSON-файл и его загрузка.

### Используемые технологии и библиотеки

Это классический пример "Vanilla JS" (чистый JavaScript) проекта с использованием мощной библиотеки для рендеринга.

1.  **Ядро проекта**:
    *   **Pannellum (v2.5.6)**: Это сердце проекта. Pannellum — это ведущая библиотека с открытым исходным кодом для рендеринга сферических панорам с использованием WebGL и CSS 3D-трансформаций. Проект использует её для всего: отображения, вращения, зума и базовой обработки хотспотов.

2.  **Технологии реализации**:
    *   **WebGL**: Библиотека `libpannellum.js` активно использует WebGL для аппаратного ускорения и плавного отображения высококачественных панорам.
    *   **CSS3**: Применяется для стилизации интерфейса, анимаций и создания красивого UI (`edit.css`, `view.css`).
    *   **JavaScript (ES6)**: Код организован в классы (`PanoramaEditor`, `PanoramaPlayer`), что делает его модульным, понятным и легко расширяемым.
    *   **HTML5 / DOM API**: Для создания динамических элементов интерфейса, обработки событий мыши и клавиатуры.

3.  **Вспомогательные технологии**:
    *   **Iframe API**: Для взаимодействия между основным окном редактора и окном предпросмотра (`postMessage`).
    *   **Fetch API / XMLHttpRequest**: Для асинхронной загрузки данных (JSON-файлов с настройками) и изображений.
    *   **FileReader API**: Для импорта JSON-файлов из локальной файловой системы пользователя.

### Сильные стороны проекта (Чем он хорош)

1.  **Полный цикл разработки (End-to-End Solution)**: Проект не просто показывает панорамы, а дает вам полный инструментарий для их создания. Это избавляет от необходимости использовать сторонние десктопные программы.
2.  **Интуитивный и удобный интерфейс**:
    *   Редактор предлагает визуальный способ работы: двойной клик для создания точки, предпросмотр для настройки. Это гораздо проще, чем редактирование JSON вручную.
    *   Все элементы управления сгруппированы и имеют четкие названия (на русском языке).
3.  **Гибкость и модульность**:
    *   Код разделен на логические классы (редактор, плеер), что упрощает поддержку и добавление новых функций.
    *   Использование JSON для хранения конфигураций делает данные тура портативными и легко редактируемыми.
4.  **Работа с внешними ресурсами**: Проект грамотно обрабатывает загрузку изображений и данных как с локального сервера, так и из внешних источников (CORS, `crossOrigin: "use-credentials"`), что позволяет использовать изображения, хранящиеся на облачных хранилищах (например, GitHub Raw).
5.  **Отличный пользовательский опыт**:
    *   Поддерживается "инерция" при вращении (friction), что делает взаимодействие с панорамой очень плавным и приятным.
    *   Есть анимация при переходах между сценами (`sceneFadeDuration`).
    *   Присутствует адаптивность и учет разных устройств (хотя и на базовом уровне).
6.  **Глубокая интеграция с Pannellum**: Проект не просто обертка над библиотекой, а активно расширяет её возможности, добавляя удобные UI-элементы для редактирования, которые в стандартной библиотеке отсутствуют.

### Области применения

- **Туризм и недвижимость**: Создание интерактивных туров по отелям, квартирам, достопримечательностям.
- **Образование**: Виртуальные экскурсии по музеям, историческим местам, лабораториям.
- **Маркетинг**: Визуализация продуктов в 360-градусном обзоре.
- **Архитектура**: Демонстрация проектов интерьеров и экстерьеров.

### Итог

Это **зрелый, хорошо продуманный и функциональный проект** для создания виртуальных туров. Он использует современные веб-технологии и предоставляет пользователю мощный, но при этом простой в освоении интерфейс для работы с панорамами. Его сильные стороны — в полном цикле разработки (от редактора до плеера), интуитивности и гибкости.
