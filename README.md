## 📖 Общее описание проекта

**PanoView360_Html** — это мощное веб-приложение для просмотра и редактирования сферических панорам (VR-туров). Это полнофункциональный редактор, который работает прямо в браузере и позволяет создавать интерактивные 360-градусные виртуальные туры без необходимости написания кода.

Проект состоит из трёх основных частей:
1. **Плеер (`viewer.html`, `panorama_player.js`)**: Для просмотра готовых панорам с поддержкой переходов по точкам.
2. **Редактор (`edit.html`, `panorama_edit.js`)**: Для создания туров, расстановки точек перехода (`hotspots`), настройки направлений камеры и экспорта/импорта данных.
3. **Превью (`viewer_preview.html`, `pannellum_preview.js`)**: Вспомогательный инструмент для выбора координат при создании точек.

### Основное предназначение

Проект предназначен для решения следующих задач:

1. **Создание виртуальных туров (визуальное повествование)**: Вы можете взять серию панорамных фотографий и объединить их в единый тур, где пользователь переходит из одной сцены в другую, кликая по специальным точкам.
2. **Редактирование в реальном времени**: Вместо того чтобы править JSON-файлы вручную, вы можете открыть редактор, кликнуть по панораме, чтобы добавить точку, и сразу же увидеть результат.
3. **Визуальное программирование (No-Code подход)**: Создание точек перехода (хотспотов) происходит через интуитивно понятный интерфейс (двойной клик для создания, предпросмотр для настройки направления).

### Ключевые функции

**Для плеера:**
- Отображение сферических панорам с полным управлением (вращение, зум)
- Поддержка переходов между сценами через `hotspots`
- Работа с внешними (по HTTPS) и локальными изображениями
- Автоматическое определение пути к изображениям (поддержка параметров `path` и `photo`)
- Автоматическая загрузка хотспотов из JSON-файлов (при наличии)

**Для редактора:**
- **Создание точек перехода (`Hotspots`)**: Двойной клик по панораме
- **Предпросмотр**: Загрузка целевой панорамы в отдельном окне для точной настройки направления камеры
- **Редактирование**: Изменение названия, текста и типа существующих точек
- **Импорт/Экспорт**: Сохранение всех настроек тура в JSON-файл и его загрузка
- **Копирование/Вставка пути**: Удобное копирование текущего пути с разделением на `path` и `photo`
- **Автоматическое определение пути**: Система автоматически определяет корневой путь из URL параметров
- **Управление хотспотами**: Создание, редактирование, удаление точек перехода с визуальным отображением на сцене
- **Контекстное меню**: Быстрый доступ к действиям через правый клик

### Используемые технологии и библиотеки

Это классический пример "Vanilla JS" (чистый JavaScript) проекта с использованием мощной библиотеки для рендеринга.

1. **Ядро проекта**:
   - **Pannellum (v2.5.6)**: Это сердце проекта. Pannellum — ведущая библиотека с открытым исходным кодом для рендеринга сферических панорам с использованием WebGL и CSS 3D-трансформаций. Проект использует её для всего: отображения, вращения, зума и базовой обработки хотспотов.

2. **Технологии реализации**:
   - **WebGL**: Библиотека `libpannellum.js` активно использует WebGL для аппаратного ускорения и плавного отображения высококачественных панорам.
   - **CSS3**: Применяется для стилизации интерфейса, анимаций и создания красивого UI (`edit.css`, `view.css`, `preview.css`).
   - **JavaScript (ES6+)**: Код организован в классы (`PanoramaEditor`, `PanoramaPlayer`, `PanoramaBase`), что делает его модульным, понятным и легко расширяемым.
   - **HTML5 / DOM API**: Для создания динамических элементов интерфейса, обработки событий мыши и клавиатуры.

3. **Вспомогательные технологии**:
   - **Iframe API**: Для взаимодействия между основным окном редактора и окном предпросмотра (`postMessage`)
   - **Fetch API / XMLHttpRequest**: Для асинхронной загрузки данных (JSON-файлов с настройками) и изображений
   - **FileReader API**: Для импорта JSON-файлов из локальной файловой системы пользователя
   - **URLSearchParams API**: Для парсинга параметров URL и работы с путями

### Сильные стороны проекта

1. **Полный цикл разработки (End-to-End Solution)**: Проект не просто показывает панорамы, а дает вам полный инструментарий для их создания. Это избавляет от необходимости использовать сторонние десктопные программы.

2. **Интуитивный и удобный интерфейс**:
   - Редактор предлагает визуальный способ работы: двойной клик для создания точки, предпросмотр для настройки. Это гораздо проще, чем редактирование JSON вручную.
   - Все элементы управления сгруппированы и имеют четкие названия (на русском языке).
   - Удобное копирование и вставка путей через буфер обмена.

3. **Гибкость и модульность**:
   - Код разделен на логические классы (редактор, плеер, база), что упрощает поддержку и добавление новых функций.
   - Использование JSON для хранения конфигураций делает данные тура портативными и легко редактируемыми.
   - Наследование от базового класса `PanoramaBase` обеспечивает единообразие кода.

4. **Работа с внешними ресурсами**: Проект грамотно обрабатывает загрузку изображений и данных как с локального сервера, так и из внешних источников (CORS, `crossOrigin: "use-credentials"`), что позволяет использовать изображения, хранящиеся на облачных хранилищах (например, GitHub Raw).

5. **Отличный пользовательский опыт**:
   - Поддерживается "инерция" при вращении (friction), что делает взаимодействие с панорамой очень плавным и приятным.
   - Есть анимация при переходах между сценами (`sceneFadeDuration`).
   - Присутствует адаптивность и учет разных устройств.
   - Контекстное меню для быстрого доступа к действиям (правый клик).

6. **Глубокая интеграция с Pannellum**: Проект не просто обертка над библиотекой, а активно расширяет её возможности, добавляя удобные UI-элементы для редактирования, которые в стандартной библиотеке отсутствуют.

### Области применения

- **Туризм и недвижимость**: Создание интерактивных туров по отелям, квартирам, достопримечательностям
- **Образование**: Виртуальные экскурсии по музеям, историческим местам, лабораториям
- **Маркетинг**: Визуализация продуктов в 360-градусном обзоре
- **Архитектура**: Демонстрация проектов интерьеров и экстерьеров
- **Культура и искусство**: Виртуальные галереи и выставки

## 🚀 Быстрый старт

### Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/MiacomSoft/PanoView360_Html.git
```

2. Откройте в браузере:
- `edit.html` - Редактор туров
- `viewer.html` - Плеер
- `viewer_preview.html` - Инструмент предпросмотра

### Базовое использование

#### Просмотр панорамы
```html
<!-- Простой плеер -->
<iframe src="viewer.html?photo=URL_ПАНОРАМЫ.jpg"></iframe>

<!-- С указанием корневого пути -->
<iframe src="viewer.html?photo=img/13.08.2026/PIC_20260813_185852.jpg&path=http://127.0.0.1/PanoView360_Html"></iframe>
```

#### Создание тура в редакторе
1. Откройте `edit.html` с параметрами:
   ```
   edit.html?photo=img/13.08.2026/PIC_20260813_185852.jpg&path=http://127.0.0.1/PanoView360_Html
   ```
2. Двойным кликом создайте точку перехода
3. Настройте URL и направление камеры через предпросмотр
4. Сохраните и экспортируйте в JSON

## 📦 Формат данных

### JSON схема для тура

```json
{
  "pitchCam": -24.41,           // Направление камеры по вертикали
  "yawCam": -6.77,              // Направление камеры по горизонтали
  "hotSpots": [
    {
      "id": 1234567890,         // Уникальный идентификатор
      "name": "Комната 1",      // Название точки
      "type": "scene",          // Тип: scene, info, custom
      "text": "Перейти в комнату",
      "pitch": -10.5,           // Координата клика (вертикаль)
      "yaw": 30.2,              // Координата клика (горизонталь)
      "targetPitch": 0,         // Направление камеры после перехода
      "targetYaw": 0,
      "panorama_url": "img/13.08.2026/PIC_20260813_190230.jpg",
      "path": "http://127.0.0.1/PanoView360_Html",
      "createdAt": "2026-01-01T12:00:00Z"
    }
  ]
}
```

### Структура JSON для хотспотов

При сохранении тура в JSON-файл, структура данных содержит:
- `pitchCam` и `yawCam` - текущее направление камеры
- `hotSpots` - массив точек перехода, каждая из которых содержит:
    - `id` - уникальный идентификатор
    - `name` - название точки
    - `type` - тип точки (scene, info, custom)
    - `text` - текст подсказки
    - `pitch` и `yaw` - координаты клика на сцене
    - `targetPitch` и `targetYaw` - направление камеры после перехода
    - `panorama_url` - относительный путь к панораме
    - `path` - корневой путь к папке с изображениями
    - `createdAt` - дата создания
